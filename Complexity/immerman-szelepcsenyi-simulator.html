What the machine is for

A nondeterministic machine accepts when some branch says yes, so it is built for existence claims: guess the path, verify it, accept. The complement asks for the opposite — a promise that no branch could have found a path — and no single branch can see that. Swapping q_acc and q_rej does not fix it: the flipped path-guesser accepts whenever some guessed walk happens to miss t, which happens all the time even when a path exists.

Immerman and Szelepcsényi (independently, 1987–88) closed the gap with inductive counting, and it gives more than PATH ∈ NL: since PATH is NL-complete, every NL language's complement lands back in NL, so NL = coNL — and the same argument gives NSPACE(s) = coNSPACE(s) for every s ≥ log n.

Where the certainty comes from

Line 14 is the whole trick. Having counted Cₖ vertices at distance ≤ k, the machine re-derives that number from scratch: it walks through every vertex u, guesses a ≤ k-step walk to it, and tallies the successes in D. A branch that guessed lazily ends with D < C, and is killed on the spot.

Only a branch that found every reachable vertex survives. For such a branch, "no u pointed at v" is not a failure of imagination — it is a proof that v is out of reach.

The rest follows: Cₙ counts everything reachable in G, a second run counts everything reachable in G − t, and the two agree precisely when deleting t removed nothing reachable — that is, when t was never reachable at all.

Why it still fits in log space

Nothing is ever stored as a set. The machine holds ten counters — k, C, C⁺, D, v, u, cur, i, and the two phase results — plus two flag bits. Each counter is a number in 0…n, so it costs ⌈log₂(n+1)⌉ bits, and the count of counters is fixed, independent of the input. The work-tape panel adds them up for the graph you are actually running.

The price is time, not space: four nested loops over V with a walk inside make it roughly n⁴ steps — comfortably polynomial, which is the usual reminder that NL ⊆ P.

Driving it yourself

Honest oracle plays the branch that always guesses well; it never trips line 14, and it is the run whose existence the theorem asserts. Random guesses shows the other side — most branches stumble into D < C and die, which is exactly the behaviour that makes a surviving branch trustworthy. Guess by hand hands you the choice at every ★, so you can try to cheat and watch line 14 catch you.

The oracle is not part of the machine. It is a stand-in for the branch that a nondeterministic machine gets for free — the reason honest runs can be assumed to exist without any branch ever computing a distance.
